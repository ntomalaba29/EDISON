# EDISON — Known Limitations

**Honesty Standard**: This register records actual current gaps and unverified boundaries so prototype capabilities are never confused with production readiness.

1. **`[PROTOTYPE COMPLETE IN AI STUDIO — PHASE 2 BLOCKS 2.1–2.7]`**: Phase 1 documentation and Phase 2 Blocks 2.1–2.6 are committed; Block 2.7 (Physical Mobile QR Scan Lab, Prototype Readiness Audit, and 11-Point VS Code Handover Package) is implemented and awaiting owner commit. Production engineering hardening (PostgreSQL, automated Playwright/Vitest suite, FFmpeg media pipeline) begins only in Phase 3.
2. **`[REDIRECT TELEMETRY != HUMAN SCAN OR DESTINATION OPEN]`**: `/r/:token` records `redirect_requested` and `redirect_issued` with User-Agent/prefetch bot filtering and 5-second deduplication. An HTTP `302` redirect does **not** prove a confirmed human QR scan (automated previewers/bots/manual browser clicks can hit `/r/:token`) and does **not** prove `destination_opened` (which requires independent verification on the target destination).
3. **`[SINGLE-HOST JSON PERSISTENCE BOUNDARY]`**: `data/edison-store.json` (`schemaVersion: 6`) uses an exclusive `O_CREAT | O_EXCL` advisory lockfile, mtime reload check, `fsyncSync`, and atomic `renameSync` to prevent corrupt or lost writes across overlapping requests on a single host. Horizontal multi-instance deployment requires migrating to PostgreSQL in Phase 3 (`TASK-P3-001`).
4. **`[SMART TV RESEARCH IS PRELIMINARY]`**: Findings in `SMART_TV_COMPATIBILITY_RESEARCH.md` and `COMMERCIAL_BREAK_DETECTION.md` are based on official platform documentation and web research, **not** empirical testing on physical Samsung Tizen, LG webOS, Android TV, or external HDMI hardware.
5. **`[NO REAL PAYMENTS OR EXTERNAL OUTREACH]`**: Payment processing (`paymentCollectionActive: false`), real KYC identity APIs, and outreach to advertisers or employers are excluded from AI Studio scope.
6. **`[LEGAL APPROVALS PENDING]`**: `COUNTRY_ACTIVATION_REGISTER.md` and `PRIVACY_SECURITY_AND_COMPLIANCE.md` identify statutory frameworks requiring qualified local legal advice; zero jurisdictions are legally approved.
7. **`[PHYSICAL QR SCAN REQUIRES OWNER DEVICE EXECUTION]`**: Block 2.7 provides the interactive Physical Mobile QR Scan Lab and persistent verification ledger (`POST /api/qa/physical-qr-tests`), but an automated container build cannot physically point a real smartphone camera at a display; physical camera verification requires Project Owner device execution via the live preview URL.
8. **`[HEADLESS BROWSER ABSENT IN CONTAINER]`**: No Chromium binary is installed in the AI Studio container; client TypeScript/Vite compilation and API E2E checks passed, while full DOM browser E2E testing (`Playwright`) is queued for Phase 3 (`TASK-P3-003`).
